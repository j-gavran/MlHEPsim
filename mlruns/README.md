# MLflow Tracking Directory

This directory contains MLflow experiment tracking data and model artifacts.

## Directory Structure

### `0/` - Default Experiment
- MLflow's automatically created default experiment
- Contains runs that weren't assigned to a specific experiment
- Experiment name: "Default"

### `302809770930480935/` - Flows Experiment
- Main experiment for normalizing flow model training
- Experiment name: "flows"
- Contains all training runs, metrics, parameters, and artifacts
- Each subdirectory inside represents a single training run with:
  - Training/validation metrics
  - Model parameters and hyperparameters
  - Plots and visualizations (density, generated samples, loss history)
  - Model artifacts

### `models/` - Model Registry
- Stores registered models and their versions
- Each subdirectory is a registered model (e.g., `MADEMOG_flow_model_gauss_rank`)
- Contains model files, metadata, and version information
- Used for model deployment and versioning

### `.trash/` - Deleted Runs
- Contains soft-deleted experiments and runs
- Can be restored or permanently deleted

## Viewing Experiments

To view experiments in a user-friendly interface, start the MLflow UI:

```bash
cd /project/atlas/users/mveldijk/MLHEPsimtest/MLHEPsim
mlflow ui --backend-store-uri file:///project/atlas/users/mveldijk/MLHEPsimtest/MLHEPsim/mlruns
```

Then open the displayed URL in your browser to browse experiments by name, compare runs, and view metrics/plots.

## Notes

- Directory names like `302809770930480935` are experiment IDs generated by MLflow
- These cannot be renamed, but experiments have human-readable names in the MLflow UI
- The actual experiment names are stored in `meta.yaml` files within each directory
